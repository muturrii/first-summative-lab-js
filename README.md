# Calculatooooooor 
A simple command-line calculator built with JavaScript and Node.js.

## Features
Addition
Subtraction
Multiplication
Division
Division-by-zero error handling
Number input validation
Calculation history
Quit option

## Technologies
JavaScript
Node.js
prompt-sync

## Installation
Clone the repository and install the dependencies:

<!-- 
git clone <repository-url>
cd <project-directory>
npm install 
-->


## Usage
Run the calculator with:

<!-- 
node index.js
 -->

When prompted, enter:
`+` for addition
`-` for subtraction
`*` for multiplication
`/` for division
`H` to view calculation history
`Q` to quit

The calculator displays the result of each calculation and stores it in the calculation history.
